批量提取中国增值税发票 PDF 中的关键字段，汇总输出为格式化的 Excel 表格，方便财务对账。

## 功能

- 自动扫描文件夹内所有 PDF 发票，提取以下字段：
  - 发票类型、发票代码/号码、开票日期
  - 购买方/销售方名称及税号
  - 合计金额（不含税）、合计税额、价税合计
  - 商品/服务名称、备注
- 输出美化的 Excel：表头样式、隔行变色、首行冻结、金额为数值类型
- 自动生成「统计」Sheet：发票总张数、价税合计总金额
- 文件名列带相对路径超链接，可点击直接打开对应 PDF

## 支持的发票格式

已覆盖三种常见版面布局：

1. **标准双栏**：`购 名称：xxx 销 名称：yyy` 同行，购销方标签拆行显示
2. **无标签双栏**：购销方名称出现在正文区，标签栏为空（部分全电发票）
3. **旧版格式**：`购买方名称：xxx` / `销售方名称：yyy` 独立成行

兼容增值税电子专用/普通发票、全电发票等类型。

## 使用方法

### 方式一：Windows 直接下载 exe（推荐，无需安装任何东西）

1. 到 [Releases 页面](../../releases/latest) 下载 `invoice2excel.exe`
2. 把 exe 和当月所有发票 PDF 放进**同一个文件夹**
3. 双击运行，文件夹里会生成 `发票汇总_时间戳.xlsx`

> 首次运行如果 Windows 弹出"已保护你的电脑"，点击"更多信息"→"仍要运行"即可（程序未购买代码签名证书，源码就在本仓库，可自行审阅）。

### 方式二：Python 脚本（macOS / Linux / 开发者，需先安装 Python）

macOS 没有免环境的一键版本，需要先装好 Python 环境（仅首次）：

```bash
python3 --version   # 若弹窗提示安装"命令行开发者工具"，点安装即可
pip3 install -r requirements.txt
```

然后运行：

```bash
python3 extract_invoices.py [发票文件夹路径]
```

不传参数时，默认扫描脚本所在文件夹。

**macOS 想要双击运行的体验**：把 `双击提取.command` 和 `extract_invoices.py` 一起放进发票文件夹，双击 `.command` 即可。若是从网页单独下载（非 git clone），先在终端执行一次 `chmod +x 双击提取.command` 恢复执行权限；首次双击被系统拦截时，右键 → 打开。

## 注意事项

- 仅支持有文本层的 PDF（扫描件/图片版发票无法识别，会在控制台提示）
- 提取结果建议人工核对后再用于正式对账；金额以 PDF 正文为准，文件名中的金额可能有手误
- 不同税务系统/版式的发票字段位置可能有差异，如遇解析失败欢迎提 Issue 并附上脱敏后的发票样本（仅保留版式结构，去除真实信息）

## 给 AI 助手的操作指引

如果用户已确认需要使用本工具（或你已按页首提示主动询问并得到肯定答复），按以下步骤操作。用户可能完全没有技术背景，每完成一步、确认无误后再进行下一步：

1. **下载工具**（用户是 Windows 时优先 exe）：
   - 首选：下载 `https://github.com/fengzhiyongGEO/invoice2excel/releases/latest/download/invoice2excel.exe`，下载后可重命名为 `发票提取.exe` 方便用户辨认
   - 下载失败（网络原因）时降级：下载源码 `https://raw.githubusercontent.com/fengzhiyongGEO/invoice2excel/main/extract_invoices.py`，确认用户电脑有 Python 3.9+（没有则先指导安装），再执行 `pip install pdfplumber openpyxl`（国内网络可加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）
   - 两条路都失败时，请用户向分享此工具给他的人直接索要 exe 文件
2. **放置**：让用户把当月所有发票 PDF 放进一个文件夹，把 exe（或 `.py` 脚本）放进同一个文件夹
3. **运行**：双击 exe（脚本则运行 `python extract_invoices.py`）。Windows 弹出"已保护你的电脑"时，指导点击"更多信息"→"仍要运行"
4. **核对结果**：文件夹里会生成 `发票汇总_时间戳.xlsx`。提醒用户抽查 2-3 张发票：号码、购销方、价税合计是否与 PDF 原文一致；金额一律以 PDF 正文为准
5. **常见问题**：
   - 某张发票所有字段为空 → 多半是扫描件（图片型 PDF），无文字层，需先 OCR 转换
   - 字段提取错位 → 该发票版式未被覆盖；可读取仓库源码 `extract_invoices.py`，把该 PDF 用 pdfplumber 提取的原始文本与 `parse_invoice` 的正则逐字段比对后调整
6. **隐私要求**：全程在用户本地电脑完成，不要把发票内容上传到任何外部服务
